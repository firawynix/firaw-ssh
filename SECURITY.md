# Security policy

Report vulnerabilities privately to `no-reply@firawynix.com.br`. Do not place
real hostnames, IP addresses, usernames, private keys, credentials, terminal
output, or backup files in a public issue.

The latest public release is supported. Host-key verification, credential
storage, encrypted profile backups, and the local automation bridge are
security-sensitive areas and should include reproduction steps that use test
accounts only.
