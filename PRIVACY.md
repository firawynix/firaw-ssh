# Privacy

Firaw SSH stores non-secret connection profiles in the application data folder
on the user's device. Passwords and key passphrases are only stored when the
user explicitly requests it and are delegated to the operating-system
credential store. Private key files remain at the path selected by the user.

The application does not operate a telemetry service and does not transmit
profiles, credentials, terminal content, or transferred files to Firawynix.
Network traffic is sent only to hosts, proxies, tunnels, and update locations
configured or selected by the user.

Questions may be sent to `no-reply@firawynix.com.br`.
